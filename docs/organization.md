# Organization Notes

Use this project like a visual project binder:

- Put raw, real-world photos in `assets/uploads/`.
- Put AI-generated concepts in `assets/renderings/`.
- Put research, screenshots, inspiration, and parcel/property images in `assets/references/`.
- Put non-image planning material in `docs/`.
- Edit `src/data/projects.js` when a room, project, budget, material, or rendering prompt changes.

For best rendering results, keep prompts tied to a source photo and a decision you need to make, such as cabinet color, exterior palette, layout, trim, lighting, flooring, or storage.
